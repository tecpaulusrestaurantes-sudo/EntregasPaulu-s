🔒 Segurança

O acesso a este painel é protegido por um PIN compartilhado (salvo no banco de dados). Recomendamos trocar o PIN padrão.

⚠️ Os dados agora ficam salvos na nuvem (Supabase) e sincronizam automaticamente entre o celular do funcionário e o computador do administrador. O PIN de acesso é uma proteção simples do lado do app — ainda não é um login de verdade, então quem tiver as chaves técnicas do projeto poderia acessar os dados diretamente. Podemos reforçar isso depois com autenticação real, se fizer sentido.
